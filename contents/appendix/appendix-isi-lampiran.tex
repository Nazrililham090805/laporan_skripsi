\section{Rumus Algoritma Tata Letak Graf \textit{Force-Directed}}
\label{lamp:rumus-graf}
Bagian ini memuat persamaan matematis dari ketiga gaya yang digunakan pada algoritma tata letak graf \textit{force-directed} pada visualisasi jaringan sanad, beserta nilai parameternya.

\begin{enumerate}
\item \textbf{Gaya tolak (\textit{repulsion})}, bekerja antar pasangan \textit{node} dan hanya diterapkan jika jarak antar \textit{node} kurang dari 320 piksel:
$$ F_{tolak} = \frac{k_r}{d^2}, \quad k_r = 2000 $$
dengan $d$ adalah jarak Euclidean antara dua \textit{node}.

\item \textbf{Gaya pegas (\textit{spring})}, bekerja pada setiap \textit{edge} dengan panjang ideal 200 piksel:
$$ F_{pegas} = (d - L_0)\cdot k_s, \quad L_0 = 200,\ k_s = 0{,}003 $$

\item \textbf{Gaya radial (\textit{radial constraint})}, menarik setiap \textit{node} menuju jari-jari cincin targetnya ($r_{target}$) sesuai peringkat sentralitas:
$$ F_{radial} = (r - r_{target})\cdot k_c, \quad k_c = 0{,}014 $$
dengan $r$ adalah jarak \textit{node} saat ini dari titik pusat.
\end{enumerate}

Setelah ketiga gaya dijumlahkan, kecepatan tiap \textit{node} diperbarui lalu dikalikan dengan faktor peredam (\textit{damping}) sebesar 0,78. Posisi awal \textit{node} ditentukan berdasarkan peringkat sentralitasnya pada cincin konsentris dengan jari-jari 180 (peringkat 1--5), 320 (peringkat 6--15), 460 (peringkat 16--30), dan 600 (sisanya).

\section{Kode Implementasi Algoritma \textit{Force-Directed}}
\label{lamp:kode-force-directed}
Berikut adalah implementasi lengkap algoritma tata letak graf \textit{force-directed} dalam bahasa JavaScript yang digunakan pada halaman Graf Relasi Perawi.

\begin{lstlisting}[style=mystyle, language=Java, frame=single, caption={Implementasi algoritma \textit{force-directed} pada visualisasi graf jaringan sanad}]
// 1. Gaya Tolak (Repulsion)
// Ftolak = kr / d^2, kr = 2000
// Hanya diterapkan jika d < 320 piksel
for (let i = 0; i < nodes.length; i++) {
  for (let j = i + 1; j < nodes.length; j++) {
    const dx = nodes[j].x - nodes[i].x;
    const dy = nodes[j].y - nodes[i].y;
    const d  = Math.sqrt(dx*dx + dy*dy) || 0.1;
    if (d < 320) {
      const f  = 2000 / (d * d);       // kr / d^2
      const fx = (dx / d) * f;
      const fy = (dy / d) * f;
      if (!nodes[i].fixed) { nodes[i].vx -= fx; nodes[i].vy -= fy; }
      if (!nodes[j].fixed) { nodes[j].vx += fx; nodes[j].vy += fy; }
    }
  }
}

// 2. Gaya Pegas (Spring)
// Fpegas = (d - L0) * ks, L0 = 200, ks = 0.003
edges.forEach(e => {
  const s = nodeMap.get(e.source);
  const t = nodeMap.get(e.target);
  if (!s || !t) return;
  const dx = t.x - s.x;
  const dy = t.y - s.y;
  const d  = Math.sqrt(dx*dx + dy*dy) || 0.1;
  const f  = (d - 200) * 0.003;        // (d - L0) * ks
  const fx = (dx / d) * f;
  const fy = (dy / d) * f;
  if (!s.fixed) { s.vx += fx; s.vy += fy; }
  if (!t.fixed) { t.vx -= fx; t.vy -= fy; }
});

// 3. Gaya Radial + Peredam (Damping)
// Fradial = (r - rtarget) * kc, kc = 0.014
// Peredam: vx, vy * 0.78
nodes.forEach(n => {
  if (n.fixed) return;
  const dist    = Math.sqrt(n.x*n.x + n.y*n.y) || 0.1;
  const radialF = (dist - n.targetR) * 0.014;  // (r - rtarget) * kc
  n.vx -= (n.x / dist) * radialF;
  n.vy -= (n.y / dist) * radialF;
  n.vx *= 0.78;   // damping
  n.vy *= 0.78;
  n.x  += n.vx;
  n.y  += n.vy;
});

// 4. Posisi Awal pada Cincin Konsentris
// Peringkat 1-5   -> r = 180
// Peringkat 6-15  -> r = 320
// Peringkat 16-30 -> r = 460
// Peringkat 31+   -> r = 600
function initPosition(gen, genIdx, genCount) {
  const radii = { 2: 180, 3: 320, 4: 460, 5: 600 };
  const r = radii[gen] ?? 300;
  if (r === 0) return [0, 0];
  const angle  = (genIdx / genCount) * 2 * Math.PI - Math.PI / 2;
  const jitter = (Math.random() - 0.5) * 20;
  return [r * Math.cos(angle) + jitter, r * Math.sin(angle) + jitter];
}
\end{lstlisting}

\noindent\textbf{3. \textit{Betweenness Centrality}}

\vspace{0.2cm}
\noindent \textit{Betweenness centrality} mengukur seberapa sering suatu simpul $v$ berada pada lintasan terpendek antara dua simpul lainnya. Sesuai implementasi pada kode Python (\texttt{normalized=True}, \texttt{weight="Inverse\_weight"}), lintasan terpendek dihitung secara berbobot menggunakan \textit{Inverse Weight} sebagai biaya antar-perawi dan hasilnya ternormalisasi:
$$C_B(v) = \frac{1}{(n-1)(n-2)} \sum_{s \neq v \neq t} \frac{\sigma_{st}(v)}{\sigma_{st}}$$
dengan $\sigma_{st}$ = jumlah lintasan terpendek berbobot dari $s$ ke $t$, dan $\sigma_{st}(v)$ = jumlah di antaranya yang melewati $v$. Faktor normalisasi: $(n-1)(n-2) = 6 \times 5 = 30$.

\vspace{0.3cm}
\noindent\textbf{4. \textit{Closeness Centrality}}

\vspace{0.2cm}
\noindent \textit{Closeness centrality} mengukur seberapa dekat suatu simpul ke seluruh simpul lain. Definisi matematis sesuai Subbab~\ref{subsubsec:metrik-sentralitas} adalah:
$$C_C(v) = \frac{n-1}{\displaystyle\sum_{u \neq v} d(v,u)}$$
dengan $d(v,u)$ = jarak terpendek dari $v$ ke $u$ (menggunakan \textit{Inverse Weight} sebagai bobot jarak).

\begin{sloppypar}
\noindent Pada sampel jaringan ini tidak semua simpul dapat dijangkau dari setiap simpul lainnya (misalnya, dari Anas bin Malik hanya bisa menjangkau Abu Hurairah). Apabila formula di atas diterapkan dengan memasukkan seluruh $n-1$ simpul ke penyebut, simpul yang tidak terjangkau menghasilkan $d = \infty$ sehingga $C_C \to 0$ untuk hampir semua simpul --- tidak informatif sebagai perbandingan. Oleh karena itu, fungsi \texttt{nx.closeness\_centrality} menggunakan adaptasi Wasserman-Faust yang membatasi penjumlahan hanya pada simpul yang terjangkau ($R(v)$) dan mengoreksi skala dengan faktor $n_r/(n-1)$:
\end{sloppypar}
$$C_C(v) = \frac{n_r}{n-1} \cdot \frac{n-1}{\displaystyle\sum_{u \in R(v)} d(v,u)} = \frac{n_r^2}{(n-1) \cdot \displaystyle\sum_{u \in R(v)} d(v,u)}$$
dengan $n_r$ = jumlah simpul yang terjangkau dari $v$ (tidak termasuk $v$ sendiri). Formula ini ekuivalen dengan formula dasar di atas ketika semua simpul terjangkau ($n_r = n-1$). Selain itu, pada implementasi aktual (kode Python tersedia di repositori GitHub pada Lampiran~\ref{lamp:tautan}), hasil WF ini dinormalisasi lebih lanjut menggunakan \textit{min-max normalization} agar seluruh nilai berada pada rentang $[0, 1]$.

\noindent Untuk contoh di bawah, $d(v,u)$ dihitung berdasarkan jumlah \textit{hop} (bukan \textit{Inverse Weight}) agar perhitungan lebih mudah diikuti:

\vspace{0.3cm}
\noindent\textbf{5. \textit{Eigenvector Centrality}}

\vspace{0.2cm}
\noindent \textit{Eigenvector centrality} menghitung nilai pengaruh suatu simpul berdasarkan pengaruh simpul-simpul yang menunjuk padanya. Skor dihitung secara iteratif dengan metode \textit{power iteration}:
$$x_v^{(t+1)} = \frac{1}{\lambda} \sum_{u\,:\,(u,v)\,\in\,E} x_u^{(t)}, \quad \text{lalu dinormalisasi}$$

\noindent\textbf{Iterasi 0} --- nilai awal seragam: $x_v = 1{,}0000$ untuk semua $v$.

\noindent\textbf{Iterasi 1} --- setiap simpul menjumlahkan skor murid-muridnya (simpul yang menunjuk padanya):
\begin{itemize}
    \item Abu Hurairah: $x_D + x_C + x_F = 1 + 1 + 1 = 3$
    \item Ibn Umar: $x_F + x_E + x_D = 1 + 1 + 1 = 3$
    \item Anas bin Malik: $x_D = 1$
    \item Az-Zuhri: $x_E + x_G = 1 + 1 = 2$
    \item Sufyan: $0$ (tidak ada murid dalam sampel)
    \item Nafi': $x_G = 1$
    \item Imam Malik: $0$ (tidak ada murid dalam sampel)
\end{itemize}
Setelah normalisasi terhadap nilai maksimum (3):\\
$x = [1{,}0000,\ 1{,}0000,\ 0{,}3333,\ 0{,}6667,\ 0{,}0000,\ 0{,}3333,\ 0{,}0000]$.

\noindent\textbf{Iterasi 2} --- menggunakan skor hasil iterasi 1:
\begin{itemize}
    \item Abu Hurairah: $0{,}6667 + 0{,}3333 + 0{,}3333 = 1{,}3333$
    \item Ibn Umar: $0{,}3333 + 0{,}0000 + 0{,}6667 = 1{,}0000$
    \item Anas bin Malik: $0{,}6667$
    \item Az-Zuhri: $0{,}0000 + 0{,}0000 = 0$ (murid Sufyan dan Imam Malik bernilai 0)
    \item Sufyan, Nafi', Imam Malik: $0$
\end{itemize}
Setelah normalisasi terhadap nilai maksimum (1,3333):\\
$x = [1{,}0000,\ 0{,}7500,\ 0{,}5000,\ 0{,}0000,\ 0{,}0000,\ 0{,}0000,\ 0{,}0000]$.

\begin{sloppypar}
\noindent Pada sampel jaringan kecil ini, simpul sumber (Sufyan dan Imam Malik) tidak memiliki murid sehingga skor mereka bertahan di $0{,}0000$. Hal ini menyebabkan Az-Zuhri, Nafi', dan Sufyan juga menuju $0$ pada iterasi berikutnya, sehingga konvergensi hanya menyisakan Abu Hurairah dan Ibn Umar dengan skor positif. Pada dataset sesungguhnya yang memiliki 177.047 simpul, keberadaan jalur siklik membuat \textit{eigenvector centrality} dapat berkonvergensi sepenuhnya dan menghasilkan peringkat yang lebih representatif.
\end{sloppypar}
