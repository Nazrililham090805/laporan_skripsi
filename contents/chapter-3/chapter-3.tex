\section{Alat dan Bahan Tugas akhir}

\subsection{Alat Tugas akhir}

Alat-alat yang digunakan pada tugas akhir ini berupa perangkat keras maupun perangkat lunak sebagai sarana pendukung antara lain:

\begin{enumerate}
	\item Laptop Lenovo IdeaPad Slim 3 (Model 82K2) dengan sistem operasi Windows 11 Home Single Language 64-bit. Laptop ini dilengkapi prosesor AMD Ryzen 5 5600H with Radeon Graphics berarsitektur 64-bit dengan 6 core dan 12 thread, memori utama sebesar 8 GB RAM, serta grafis terintegrasi AMD Radeon Graphics.
	Alat ini berfungsi sebagai perangkat utama dalam menjalankan seluruh proses pengolahan data, pemrograman, dan pengembangan web.
	\item Visual Studio Code versi 1.125.1 digunakan sebagai lingkungan pengembangan terintegrasi (Integrated Development Environment/IDE) dalam penelitian ini. Visual Studio Code digunakan untuk menulis, menjalankan, dan mengelola kode Python berbasis \textit{Jupyter Notebook (.ipynb)} yang mencakup proses pra-pemrosesan data, pembangunan graf jaringan sanad, perhitungan sentralitas perawi, dan pengembangan front-end. 
	\item Python versi 3.13.13 digunakan sebagai bahasa pemrograman utama dalam pembersihan dan pengolahan data.
	\item Pustaka NetworkX versi 3.6.1 digunakan untuk membangun graf dan menghitung sentralitas jaringan perawi.
	\item JavaScript yang merupakan bahasa pemrograman yang digunakan untuk membuat halaman web menjadi dinamis, interaktif, dan responsif.
	\item React versi 18.3.1 merupakan library JavaScript yang digunakan untuk pembuatan komponen UI yang reusable dan efisien dalam merender ulang data yang berubah, cocok untuk dashboard yang menampilkan data dinamis.
	\item Supabase digunakan sebagai backend dan database aplikasi, menyediakan penyimpanan data, autentikasi pengguna, dan API secara otomatis.
\end{enumerate}

\subsection{Bahan Tugas akhir}
Bahan yang digunakan pada tugas akhir ini berupa data hadis. Data ini didapatkan dari studi Mghari \textit{et al} \cite{MGHARI2022108540}. Data tersebut bersifat statis dalam format CSV (\textit{Comma-Separated Values}) yaitu diantaranya:

\begin{itemize}
	\item \textbf{sanadset.csv} memuat lebih dari 650.986 rekaman hadis yang bersumber dari 926 kitab hadis Arab klasik, dengan masing-masing rekaman terdiri atas 6 variabel yang mencakup informasi kitab asal, nomor hadis, teks hadis, Matn, daftar perawi, dan jumlah perawi.

	\item \textbf{hadith\_samples.csv} berisi sepuluh contoh hadis dalam bahasa Arab. File ini digunakan untuk membantu memahami format dan struktur data sebelum dilakukan pengolahan terhadap keseluruhan korpus.

	\item \textbf{translated\_samples.csv} memuat versi terjemahan bahasa Inggris dari sampel hadis yang tersedia. File ini memudahkan pemahaman isi hadis serta pembedaan komponen Sanad dan Matn, khususnya bagi peneliti yang tidak menggunakan bahasa Arab.

	\item \textbf{books.csv} mendokumentasikan daftar kitab-kitab klasik yang menjadi sumber pengumpulan data. File ini berperan menjaga ketertelusuran data sehingga setiap hadis dapat dirujuk kembali ke sumber kitab asalnya.
\end{itemize}

Dari keempat file tersebut, dataset yang digunakan secara langsung dalam penelitian ini adalah \textbf{sanadset.csv}. Dataset ini dipilih karena memiliki cakupan data yang paling lengkap dan relevan, yakni memuat informasi perawi beserta rantai sanad secara keseluruhan yang dibutuhkan dalam pembangunan graf jaringan sanad dan perhitungan sentralitas perawi.



\section{Metode yang Digunakan}

Bagian ini membahas metode atau cara yang akan digunakan dalam penelitian, tahapan 
penerapan metode, dan desain penelitian (misalnya apakah penelitian akan menggunakan 
eksperimen di Laboratorium atau di lapangan, misalkan saja penelitian biomedis atau 
penelitian alat ukur hama yang dapat dilakukan di laboratorium ataupun di lapangan, atau menggunakan metode survei (misalnya untuk teknologi Informasi), studi kasus, atau analisis dengan perangkat lunak (ETAP, LTSpice, dst), atau \textit{prototyping} (pembuatan perangkat keras).

Bagian ini juga membahas bagaimana data [akan] dianalisis, apakah dengan membandingkan keluaran beberapa alat ukur, membandingkan dengan standar atau bagaimana.

Bagian ini membahas pertimbangan etis penelitian dan [potensi] masalah serta
